## 1. P1-1 · Bookmark force repair 表述

### 修改前

§3.1.1「故意不画」段写：「每日 alarm / **Settings 手动 force repair** …」——与产品书签对账 Normative（**禁止** Settings 暴露修复 UI）及调用面冲突。

### 证据（复核）

| 调用                                               | 证据                                                                                      |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `repairChromeBookmarksWithMemory({ force: true })` | **仅** `extension/src/background/listeners/chrome-bookmark-repair-alarm.ts`（每日 alarm） |
| 无 `force` 的 full repair                          | `finalizeChromeBookmarkSyncAfterImport` → `repairChromeBookmarksWithMemory()`             |
| Settings / pages / handlers                        | **无** `repairChromeBookmarksWithMemory` 调用                                             |
| Normative                                          | 产品文档：禁止 Settings「修复」类用户操作                                                 |

### 修改内容

- 删除「Settings 手动 force repair」归因。
- 写明：① finalize 每 SW 会话至多一次（无 force）；② 每日 alarm `force: true` 绕过会话限制。
- 明示：Settings 只开/关灌库（可 `ensureChromeBookmarksImported`），**不是**手动 force repair。
- `registry.json` → `runtime.bookmark-chrome-ingest.notes` 同步上述口径。

### 未改

- 业务代码 / `chrome-bookmark-sync-service.ts` JSDoc（仍可能写「Settings 手动修复」——属代码注释债，须另 Brief）。
- Mermaid 边本身（图内本无 Settings force 边）。
