# 全局图表覆盖状态重新盘点（2026-10-31 · 第十七阶段）

> **本轮约束：** 只审计、分析、写报告；**不**改 registry / Mermaid / 宿主导航 / 业务代码 / 测试 / 工具脚本。  
> **口径：** 以**当前** `registry.json` + 锚点宿主 + 源码入口为准；**禁止**照搬 2026-10-30 第三阶段的「10 张 / 五大缺口」结论。

## 0. 一句话结论

登记图现为 **15** 张（**14** `implemented` + **1** `planned`）；第三阶段点名的 **P0 Auth mint / P0 云同步 / P0 Outcome / P1 Omnibox / P1 Bookmark 灌库** 均已有独立 `implemented` 图，且经后续语义/Registry 校准。  
**主链找东西 + 账号接通 + 摘录上云** 已有可导航表达；剩余真正缺口集中在 **登录迁移门闸、退出解耦 / website-session 反铸、Billing、Getting Started、Embedding 无感维护**——多为「散文/ASCII 够用或故意折叠」，**不宜为覆盖率批量补图**。  
下一阶段优先：**高漂移图按需语义复审** 与 **卫生/Registry P2（可选）**，而非再开一轮大覆盖扩张。
