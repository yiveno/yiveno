## 5. 硬过滤选型理由与误杀风险

**为何硬过滤：** 产品要「明确排除的文档不得进邻域」；软惩罚只降分，仍可 Top1 误报（L2 意图 A 已演示）。

**误杀风险（仍存在）：**

| 风险                                 | 缓解                                            |
| ------------------------------------ | ----------------------------------------------- |
| 排除词过泛（如单独 `day`）           | `EXCLUDE_TOO_GENERIC_TERMS` 剥除                |
| 主题词误入 exclude（如 yellowstone） | 与 contentTerms 冲突 → 保留正词                 |
| 排除过猛空池                         | 诚实空邻域；不因排除单独时间 soft 回退          |
| LLM 抽错范围                         | Prompt + 确定性 map；规则保守不猜               |
| 不确定表达误抽                       | `not sure` / `don't remember` 等 → 不抽 exclude |

## 6. 仍未解决 / 已知边界

1. **无通用逻辑推理：** 「not packing somehow weirdly」等非保守表面 → 不抽 exclude（只剥标记）。
2. **LLM 可能把 day-hike 拆成 day+hike：** day 被剥；靠 hike/packing/checklist 仍可硬滤清单。
3. **Side Panel 真机 UI** 本批未跑 MCP（纯理解+过滤契约）；keyword 编排单测已覆盖 A/B。
4. **不进 Phase C / 不换 Embedding / 无 Reranker。**
