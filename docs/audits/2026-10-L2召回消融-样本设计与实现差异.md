> **顺序硬约束：** 本文先于真实跑数落盘。标签歧义处标 `labelConfidence=ambiguous`，**不**自行猜唯一正解。

## 1. 实验回答什么 / 不回答什么

## 2. Hybrid 实验 vs 生产（实现差异 · 跑前钉死）

| 机制                                 | 实验 Hybrid                                                                                        | 生产 hybrid 主路径      | 本实验是否纳入   |
| ------------------------------------ | -------------------------------------------------------------------------------------------------- | ----------------------- | ---------------- |
| Outcome 对 `applyStoredOutcomePairs` | **不调用**                                                                                         | 融合后可读 Outcome 软调 | **否**           |
| 同域加成 / 页上下文                  | `pageContextMode=none`                                                                             | 可 boost / restrict     | **否**           |
| 候选截断                             | keyword 池≈100；semantic=`HYBRID_SEMANTIC_NEIGHBOR_*`；collapse=`RECALL_RESULT_POOL_LIMIT(+extra)` | 同常量族                | **是（同常量）** |
| 时间硬筛 / 槽位软加成 / 佐证软罚     | 与生产同函数族                                                                                     | 同                      | **是**           |
| RRF + preferKeywordLeader            | `fuseKeywordAndSemanticPools`                                                                      | 同导出函数              | **是**           |
| LLM framing / polish                 | 无                                                                                                 | 条件触发                | **否**           |
| 理解层                               | 固定 `goldParsed`                                                                                  | 实时 parse/LLM          | **故意冻结**     |

**结论句：** 实验 Hybrid =「冻结理解 + 无 Outcome/同域/NLG 的 RRF 覆盖评测」，**不是**生产端到端收益。

## 3. 指标口径（扩充）

| 指标                 | 子集 | 口径                                                                |
| -------------------- | ---- | ------------------------------------------------------------------- |
| Recall@1/5/10        | hit  | `include_miss_as_zero`；分母=hit 条数                               |
| MRR                  | hit  | 同上；miss → 贡献 0                                                 |
| nDCG@5 / nDCG@10     | hit  | 二元单相关；同上                                                    |
| `candidateMissCount` | hit  | 目标**不在全候选列表**                                              |
| `rankWrongCount`     | hit  | 在列表内但 **R@5=false**（位次问题，留给 Phase C 解释，本层只计数） |
| `negFP`              | miss | 禁止 ID 进入前 K；记 rank + 策略分歧；**分母≠ Recall**              |

三策略共用：同一 `buildRetrievalAblationCorpus()` 快照、同一 `goldParsed`、同一 `RETRIEVAL_ABLATION_NOW_MS`、同一过滤/融合函数。
