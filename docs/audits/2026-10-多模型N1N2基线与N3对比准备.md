### 2.3 N2 解读（非分模结论）

- Flash 相对规则：**抬升 3 条 stretch**，但 **must 回归 2 条** → 现网 Flash **不是**「L2 无代价赢家」。
- 回归以 confidence / 多余 contentTerm 为主，属 prompt/schema/金标张力，**不**自动等于「该换更强模型」。
- 直连 API 快照与生产 Gateway 路径 **不完全同构**（见模型名差异）；N3 对比须固定同一路径。

### 3.1 核实结论（改码前 FACT）

| 点                                      | 事实                                                                                                |

### 3.4 候选对比怎么跑（待你指定 model id）

```bash
# A 基线（已验证）
cd extension && PARSE_GOLD_LLM_MODEL=deepseek-v4-flash PARSE_GOLD_LLM_GATE=all bun run parse-gold:llm

# B 候选（换 MODEL；新进程；JSON 默认落 snapshots/）
cd extension && PARSE_GOLD_LLM_MODEL=<candidate> PARSE_GOLD_LLM_GATE=all bun run parse-gold:llm
```

固定：`PARSE_GOLD_CASES` · `PARSE_GOLD_NOW_MS` · temperature **0** · maxTokens **400** · `disableThinking`。  
评分：JSON 内 `layers.L1_schema` / `L2_parse_gold`；`L3_recall_hybrid=NOT_RUN`。  
费用：用报告 `tokensSummary`（实测 usage）；无 usage 则为 **MISSING**——禁止手算冒充。

**通过门槛（建议 · 非本轮裁决）：** 候选 L2 must ≥ Flash；regressed 集合可解释；仍须 N1 触发表才谈生产分模。
