# B2 · 排除匹配收紧落地

## 1. 匹配契约（已实施）

排除**专用**匹配（`fieldHitsExcludeTerm`），**不**再调用正佐证 `fieldCorroboratesTerm` / 裸 `includes`。

| 规则       | 行为                                                 |
| ---------- | ---------------------------------------------------- |
| 分词       | `[^a-z0-9]+`（`-` 为边界）                           |
| 单词       | token ∈ 排除屈折集，或 token 屈折集 ∩ 排除屈折集 ≠ ∅ |
| 连字符短语 | 连续 token 对齐各段（`day-hike` ≡ `day hike`）       |
| 正佐证     | 不变                                                 |

## 2. 正反例结果（FACT · 单测 19 passed）

| 排除词                          | 命中                                 | 不命中                                 |
| ------------------------------- | ------------------------------------ | -------------------------------------- |
| `hike`                          | day-hike 清单、day hike、hiking tips | **hikers** lodging、Ashike、纯 lodging |
| `day-hike`                      | day-hike、day hike                   | hikers-only、lodging                   |
| `packing`                       | packing checklist                    | 无 packing 的 lodging                  |
| LLM 集 `hike+packing+checklist` | 清单                                 | lodging、hikers                        |

空池：`no_match`；Hybrid 降级同 parsed 不回灌 hiking。  
行为否定 / 不确定 / 普通查询：exclude 空。

## 3. 诊断（非 UI）

`listExcludeTermsHittingItem(item, excludeTerms)` → 实际命中的排除词列表。  
可与：模型原始 proposal → `normalizeExcludeContentTerms` → 生效 exclude → 本函数 对照。

`Heard as`：**未改**（不展示 exclude）。

## 5. 剩余风险

| 风险             | 说明                                                                    |
| ---------------- | ----------------------------------------------------------------------- |
| 屈折不对称       | `hike`→`hiking` 靠字段侧反向屈折；`hikers` 不产生 `hike`（有意）        |
| 多词无连字符短语 | `day hike packing` 作单一 exclude 短语未建模（当前为多 token 任一命中） |
| L2 离线 fuse     | 仍无 exclude（实验基线）                                                |
