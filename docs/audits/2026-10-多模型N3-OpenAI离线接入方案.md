## 2. GPT-5.4 mini 官方参数约束（FACT · 对照现状）

来源：

- [GPT-5.4 Mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)（2026-10-30）
- [Chat Completions 参考](https://developers.openai.com/api/reference/resources/chat)
- [Reasoning models](https://developers.openai.com/api/docs/guides/reasoning)
- GPT-5.x 参数兼容说明（[Using GPT-5.2](https://developers.openai.com/api/docs/guides/latest-model/gpt-5.2.md) 等）：`temperature`/`top_p`/`logprobs` **仅**在 `reasoning_effort=none`（或等价）时可用；非 `none` 带这些字段会报错

| 官方                                                              | 对本任务建议                                                    | 现状缺口                                                                              |
| ----------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Chat Completions **Supported**                                    | 继续 `/v1/chat/completions`                                     | 协议 OK                                                                               |
| `reasoning_effort`: **none**（默认）/ low / medium / high / xhigh | 槽位 JSON → 显式 **`none`**（低延迟、贴近 Flash「关思考」意图） | 现状发 DeepSeek `thinking`，**不是** `reasoning_effort`                               |
| `max_completion_tokens`（含可见输出 + reasoning tokens）          | 用 **400**（与现 Flash 离线 `maxTokens` 对齐）                  | 现状只发 **`max_tokens`**（文档：deprecated；对 o-series **不兼容**；gpt-5.4 族宜换） |
| `temperature`                                                     | 在 **`reasoning_effort=none`** 下可保留 **0**（对齐现评测）     | 若误设 effort≠none 且带 temperature → 官方称会错                                      |
| DeepSeek `thinking`                                               | **不要发送**                                                    | 现状默认发送                                                                          |

**目标请求体（实施后 · 离线 OpenAI profile）：**

```json
{
  "model": "gpt-5.4-mini",
  "messages": ["…与现 Prompt 相同…"],
  "max_completion_tokens": 400,
  "temperature": 0,
  "reasoning_effort": "none"
}
```

**禁止出现：** `thinking`。

## 3. 最小接入方案（RECOMMENDATION · 确认前不改码）

### 3.1 设计原则

1. **默认行为不变** → DeepSeek 离线 / 开发直连路径继续发 `thinking` + `max_tokens`（避免回归 Flash 基线工具链）。
2. **OpenAI 仅离线 opt-in** → CLI 设 profile 或显式 env 时换 body；**不**改 Worker `AiChatProvider`。
3. **不改** Prompt / Zod Schema / Filter / Hybrid / 生产 env / 生产模型。

### 3.2 参数映射

| 概念               | DeepSeek 离线（保持）            | OpenAI `gpt-5.4-mini` 离线                                                     |
| ------------------ | -------------------------------- | ------------------------------------------------------------------------------ |
| baseUrl            | `https://api.deepseek.com`       | `https://api.openai.com`                                                       |
| model              | `deepseek-v4-flash` 等           | `gpt-5.4-mini`（可钉 `gpt-5.4-mini-2026-03-17`）                               |
| 长度上限字段       | `max_tokens: 400`                | `max_completion_tokens: 400`                                                   |
| 温度               | `temperature: 0`                 | `temperature: 0`（配合 effort=none）                                           |
| 思考控制           | `thinking: { type: "disabled" }` | **`reasoning_effort: "none"`**；**omit** `thinking`                            |
| Auth               | `Authorization: Bearer …`        | 同形                                                                           |
| Key 来源（仅进程） | 现有 DeepSeek 变量               | 你提供后的 `OPENAI_API_KEY` 或 `PARSE_GOLD_LLM_API_KEY`（**本 Agent 不申请**） |

### 3.3 预计改动文件（实施阶段）

| 文件                                                                | 动作                                                                                                                                     | 生产影响                                               |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| `extension/src/core/recall/understand/openai-compatible-chat.ts`    | 增可选 `compatProfile: 'deepseek' \| 'openai'`（或等价开关）；按 profile 组装 body                                                       | **无**（仅被离线 CLI / 显式调用方使用；默认 deepseek） |
| `extension/scripts/run-parse-gold-llm.ts`                           | 读 `PARSE_GOLD_LLM_COMPAT=openai`（或 baseUrl 含 `api.openai.com` 时启用 openai profile——**推荐显式 env，禁止静默猜测**）；写入报告 meta | **无**                                                 |
| `extension/src/core/recall/eval/parse-gold-llm-report.ts`           | 可选：meta 增 `compatProfile` / `reasoningEffort` / `maxCompletionTokens`；可选成本估算                                                  | **无**                                                 |
| 对应 `*.test.ts`（新建或扩）                                        | 断言 openai profile **不**含 `thinking`、含 `max_completion_tokens`+`reasoning_effort`                                                   | **无**                                                 |
| Worker / Prompt / Schema / Filter / Hybrid / wrangler / 生产 Secret | **不改**                                                                                                                                 | —                                                      |

### 3.4 明确不做（本准备与后续实施默认）

- 不接 `response_format.json_schema`（保持与 Flash 基线同「prompt JSON + Zod」，避免对照不公）
- 不上 Responses API（Chat Completions 已 Supported）
- 不接 Google、不测 Pro
- 不写生产 `AI_PROVIDER=openai`
