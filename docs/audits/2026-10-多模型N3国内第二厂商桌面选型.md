# N3 国内第二厂商桌面选型（Qwen 优先）

> **背景：** 开发机大陆网络下 OpenAI 控台/Key 摩擦大；Gemini 官方可用地区不含大陆。生产已是 DeepSeek → **再换 DeepSeek 无第二厂商意义**。  
> **本轮：** 仅官方文档 + 仓库契约。**未**申请 Key、**未**调候选 API、**未**改生产。  
> **并行不变：** Pro `INSUFFICIENT_EVIDENCE` + P0；Flash 基线保留；OpenAI 离线**评测暂停**（代码可留）。

**标签：** FACT / INFERENCE / UNKNOWN / RECOMMENDATION。

## 0. 结论摘要

| 项                 | 内容                                                                                                                                    |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| **提出候选（≤2）** | ① 阿里云百炼 **`qwen-flash`** · ② 同厂 **`qwen-plus`**                                                                                  |
| **推荐初筛顺序**   | **先 flash，后 plus**（同厂质量梯；不是再找一只 DeepSeek）                                                                              |
| **为何换道**       | 大陆可控台拿 Key + OpenAI 兼容 Chat Completions；价以人民币计价；适合「clue → JSON 槽位」短调用                                         |
| **明确不做**       | 不以榜单认定 NLU 更强；不把本选型写成生产默认换模；不测 Gemini/OpenAI（可达性暂停）                                                     |
| **本轮状态**       | **`qwen-flash` 首轮评测完成**（L2 must 25/35）；详 [DashScope 方案 §0.1](./2026-10-多模型N3-DashScope离线接入方案.md)；`qwen-plus` 可选 |

## 1. 现有离线契约（FACT · 约束）

| 约束                                                            | 含义                                                                   |
| --------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `POST {base}/v1/chat/completions` + Bearer                      | DashScope **OpenAI 兼容模式**可贴                                      |
| 默认 `compat=deepseek` 会发 `thinking`                          | **禁止**原样打百炼（与 OpenAI 同理）                                   |
| `compat=openai` 发 `max_completion_tokens` + `reasoning_effort` | **不宜**直接复用给百炼（官方参是 `max_tokens` / `enable_thinking` 等） |
| NLU 现状：prompt JSON + Zod，**不**传 `response_format`         | 初筛与 Flash 基线同契约；结构化 API 为可选加固，非本轮必接             |
| 生产 Worker                                                     | 仍仅 `AI_PROVIDER=deepseek`；本选型**只**服务离线 parse-gold           |

→ 确认后需新增例如 **`PARSE_GOLD_LLM_COMPAT=dashscope`**（或等价）：`max_tokens` + **omit** DeepSeek `thinking` + **omit** OpenAI `reasoning_effort`；可选显式 `enable_thinking: false`（须文档/实测）。

## 5. 为何值得用 37 条 parse-gold 初筛

与美系选型同法：

1. 同输入、同 Prompt/Schema/`nowMs`、同 L1/L2 judge，对照 Flash verify。
2. 验证的是**跨厂商**槽位抽取，不是榜单。
3. L3 固定 **`NOT_RUN`**。
4. 过筛建议（RECOMMENDATION）：L2 must ≥ 27/29 且回归可解释，再谈是否值得 Worker 侧挂第二上游。
