## 7. 裁决释义

### 为何不是 `CANCEL_PRO`

取消条件是「确认与现有 Flash 是同一模型」。  
现有官方材料**不能**确认同一性（Pricing/Changelog/list-models 叙事指向独立 Pro；仅 news 指向 Flash）。→ **禁止 CANCEL_PRO**。

### 为何不是 `RUN_PRO`

开跑 quality 对比的前提是「确认实际路由」或至少映射无官方冲突。  
**news260910 与 Changelog/Pricing 冲突未解**；无零配额手段可解。→ 按 Brief **先不跑** → **禁止 RUN_PRO**。

### 故：`INSUFFICIENT_EVIDENCE`

| 动作                               | 状态                                         |
| ---------------------------------- | -------------------------------------------- |
| 候选 API / 全量 parse-gold for Pro | **暂停（P0 已确认）**                        |
| 生产行为                           | **不变**                                     |
| Q2/Q3                              | 仍 **UNKNOWN**；**未**改写成同模或异模已确认 |
