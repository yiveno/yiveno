# 自然 clue 采样协议（决策主线 · 2026-09-10）

> **性质：** 研究协议（Non-normative 操作）；**决定**哪些线索维度进 `recall-eval` must / 产品投入。  
> **不等于：** AI 按形态表代写口语批（SOP §2.2）——那是履约抽检；本协议量的是**真人首句自发痕迹**。  
> **不等于：** ADR-011（时间硬/软已落地）——工程刀；本协议仍决定后续刀砍哪。  
> **Normative 门槛：** 产品文档 §5.9；主 SOP：[`solo-researcher-sop.md`](./solo-researcher-sop.md)

---

## 0. 为何单独开协议

| 问题      | AI 口语批（§2.2）   | 本协议                                   |
| --------- | ------------------- | ---------------------------------------- |
| clue 谁写 | Agent 按形态表      | **参与者首句自发**                       |
| 回答什么  | 「邻域有没有 gold」 | 「人自然会想起哪类痕迹」+ 产品是否用得上 |
| 用途      | 回归 / 机制坑       | **分配工程优先级 + must 扩面**           |

**禁止：** 先翻历史 / Library / 倒排再编 clue；用检索式冒充首句；把采样前基线与 ADR-011 后混计却不标注。

## 1. 单次任务流程（≈8–12 分钟）

```
[1 锁目标] 参与者心里选定「想找回的一条」真实 Memory
           （研究员可事后对 gold id；任务中禁止翻历史 / Library）
[2 首句]   只问：「你还记得什么都行。」
           录下第一句完整口语（美式英语优先；内部自测可中文备注旁注）
[3 标注]   对首句勾选出现的维度（可多选）— 见 §2
[4 测 1]   用**首句原样**（或最小清洗：去口头禅）作 clue₁ → Side Panel UI 提交
           记：TTE-V、首屏邻域是否含目标、是否 no_match、Framing 时间措辞
[5 测 2]   请再补一句「还能想起别的吗？」→ clue₂（可与 clue₁ 合并或第二轮）
           同样记 TTE / 邻域 / no_match；**勾选 clue₂ 维度**
           **（2026-10 暗线 H2）** clue₁ 正式 `miss` 时 clue₂ **必做**，并记相对 clue₁ 的新增维度码
           进度清单：`docs/archive/research/dual-thread-notes/2026-10-10-补采检查清单-NS至10.md`
[6 确认]   维护者/研究员：yes / miss / no（目标是否就是那条；首句是否像人话）
[7 落盘]   填 sessions/natural-sample-*.md；失败勾 taxonomy
```

**冷启动：** 新无关 Tab · Side Panel · New find。  
**MCP：** 允许 Agent 代填 UI（`fill`/`click`），但**首句必须来自真人**；禁止 Agent 改写首句抬分。

## 2. 首句维度标注（可多选）

| 码    | 维度        | 用户自然会说（例）                       | 系统当下可诚实利用                 |
| ----- | ----------- | ---------------------------------------- | ---------------------------------- |
| **T** | 时间 / 时期 | last week / a while ago / 「换工作那阵」 | 保存时间；人生事件需附注或未来锚   |
| **S** | 来源 / 场景 | Stripe / Substack / 「好像博客」         | domain / URL / 标题                |
| **G** | 当时目标    | 「为重试失败存的」                       | 附注、摘录、语义                   |
| **C** | 内容大意    | 「讲标签为何失败」                       | 标题、摘录、语义                   |
| **D** | 显著细节    | 「蓝色图」「语气很尖」                   | 仅当正文可支持；禁止臆造           |
| **R** | 关系 / 顺序 | 「看完 X 后存的」                        | 时间邻近；未来同次捕获邻域         |
| **F** | 感受 / 外观 | 「让我很焦虑」                           | **仅软语义**；禁止当已核实情绪硬滤 |

**纪律：** 「用户说出的线索」≠「系统已知事实」。无字段支撑时诚实不硬滤、不伪匹配。

## 3. 计量（每人 / 每目标）

| 指标                | 定义                                                                         |
| ------------------- | ---------------------------------------------------------------------------- |
| **首现维度**        | 首句勾选集合；记主锚（最醒目的一个码）                                       |
| **TTE-V₁ / TTE-V₂** | clue₁ / clue₂ 首次看见可自验证据的秒数（或超时）                             |
| **Neigh₁ / Neigh₂** | 首屏（或 Show all 可见邻域）是否含 gold / 同页 alt                           |
| **Empty₁ / Empty₂** | 是否 `no_match` / Nothing matched（并注是否 low 时间硬空——ADR-011 后应少见） |
| **IB**              | refine / 误点次数                                                            |

**批大小建议：** 先 **5–8 个真实目标**（同一参与者库）即可出频率方向；再扩。

---

## 4. 汇总 → must / 产品

采样攒够一小批后：

1. 统计各码**首现频率**与 **T+S / T+G / S+G** 等组合频率
2. 列出 Empty 的 taxonomy（解析 / 硬时间 / 类型硬空 / 排名 / 无信号）
3. **再**决定：
   - 哪类口语进 `recall-eval` **must**（少而硬；优先真实首句匿名化）
   - 下一刀产品（来源软加权 / 目标·附注 / 类型对齐 quote↔excerpt 等）
4. **不**因单次 miss 扩内容灰名单
