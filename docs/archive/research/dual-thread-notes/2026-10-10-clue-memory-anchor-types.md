## 1. 事先假设（可证伪）

> 写在看新一批采样结果之前。编码约定对齐自然 clue 采样维度（见上游协议 §2）：  
> **C** 内容大意 · **G** 当时目标/用途 · **S** 来源/场景 · **T** 时间 · 以及「主题词」可并入 C/G 的粗主题表述。

- **H1（锚频次）：** 在「心里锁定真实目标、禁止翻库、首句自发」条件下，首句至少带 **C 或 G** 之一的比例 **≥ 60%**；纯 **T**（仅时间、无内容/用途锚）单独成句的比例 **≤ 25%**。
- **H2（补句增益）：** 当 clue₁ 未命中邻域（首屏不含 gold）时，clue₂（「还能想起别的吗？」）若新增 **G（为何保存）或 S（来源场景）**，比仅重复/加长 **C**，更能把 gold 送进 top-3。（操作化：在 clue₁ miss 子集上，比较「补 G/S」vs「仅扩 C」的邻域命中率。）
- **H3（用途 vs 标题）：** 对「记得为何保存、说不出准确标题」类目标，以 **G 主导** 的 clue 在 Hybrid 路径上的邻域命中率，不低于以稀有专名/标题碎片主导的 clue（在同一批 gold 上对照）。

**若假设不成立，预期看到什么：**

- H1 否：首句大量只有时间/感受（F）或空泛词 → 说明自然提取更「虚」，产品应更重追问/主题门，而非假设用户会先给内容词。
- H2 否：补 G/S 不优于扩 C → 不宜把「用途/场景」当成默认第二刀，应改投其它维度或理解层。
- H3 否：G 主导明显弱于标题碎片 → 「记得为什么」在当前索引下难用，暗线结论要下调 G 的产品优先级。

## 2. 用户问题 / 现象（贴明线）

用户常用自然语言描述想找的东西，却记不住标题/URL。明线要决定：理解与检索应优先吃哪类自发痕迹，才更快进正确邻域。  
暗线要问：这反映的是人脑提取时更容易激活的锚，还是界面/算法塑造出的说话习惯。

## 4. 替代解释（事先列出）

1. **界面诱导：** Side Panel placeholder / Idle 样句已偏向某种说法，首句不「自然」。
2. **库构成偏差：** 书签多、摘录少（或相反）会抬高 S 或 C。
3. **算法已偏向：** Hybrid/倒排对某类词更敏感 → 命中率差反映系统，非记忆锚。
4. **研究者熟悉度：** 维护者自采会「会说话」，高估 C/G 清晰度。
5. **协议执行漂移：** 翻过 Library 再编首句 → 污染 H1。

## 5. 验证方法

- **对照 / 条件：** 冷启动 New find；禁翻库；首句真人；维度双人（或隔日）可复核；H2/H3 在 clue₁ miss 子集与同批 gold 上比。
- **独立评估：** 邻域是否含预先锁定的 gold id（非事后挑好看的结果）；可另跑同 clue 的 keyword-only vs Hybrid 作敏感性分析（标清）。
- **成功 / 失败判据：** 见 §1 各 H 的比例/命中阈值；未达样本量 → 结果栏填「不足」，**不**下调或上调 H 措辞来迎合数字。
- **科学边界：** 支持 H 只能说「在本协议 + 本库环境下的提取行为」；**不得**写成普遍人脑定律。

## 6. 结果（首批汇总 · 2026-10-10）

| 假设 | 结果                    | 备注                                                                            |
| ---- | ----------------------- | ------------------------------------------------------------------------------- |
| H1   | **方向支持 · 样本不足** | 7/7（6/6 独立首句）含 C 或 G；纯 T=0；但 n&lt;10 且仅 P001 → **不升格为已验证** |
| H2   | **不足**                | clue₁ miss 的正式样本（NS05/06）无补句对照；NS07 有 clue₂ 但未增 G/S/C 锚       |
| H3   | **不足**                | 无「记得为何保存、说不出标题」预标注子集；NS02 为 S+G+T 命中，不能单证 H3       |

**置信度：** **低** —— 单人、n 小、正式履约分子仅 3；NS05/06 同 clue 双目标会放大 C 维 miss 印象；界面/库/算法替代解释均未排除。

**本批额外现象（非事先 H，记观察、不作结论）：**

- C 主锚仍可 **miss**（检索侧：字面鸿沟 / 缺 embed / Hybrid 漂）→ 暗线「人会说 C」≠ 明线「C 够用」。
- 弱 G、无 C → 正确走 `missing_topic`（NS07）→ 与主题锚门禁同向，但是**产品规则**证据，不是脑机制定律。
- 作废样本（NS01/03/04）仍显示人常带 C/G——计「人会这么说」时有用，不计履约率。

## 7. 对产品的含义（若有）

- **现阶段仍不改代码、不调权重。** H1 仅方向支持，未达事先样本量。
- **不必**因本批开「用途优先追问」明线（H2 无数据）。
- 明线若继续：优先补采至 ≥10 **独立**首句（协议锁 gold），并在 miss 会话强制记 clue₂ 维度——专为 H2。
- 观察项可进工程 backlog（**仅明线 / 已有根因**）：C 维英/中字面鸿沟、增量 embed——与本暗线笔记脱钩，勿冒充「更懂大脑」。
- 明确**不**改什么：不把维度码做成灰名单通解；不对外宣传脑科学结论。
