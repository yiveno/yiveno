## 1. 每条新样本 · 强制步骤

复制 [`_TEMPLATE-natural-sample.md`](../tte-beta-2026-09/sessions/_TEMPLATE-natural-sample.md) → `P001-NS0N-natural-sample.md`（本地可含原文；提交前剥离或 gitignore）。

### 开跑前

- [ ] 心里锁定**一条确定存过**的 Memory（类型/大概域即可）
- [ ] **禁止**翻 Library / 历史 / 倒排后再编首句
- [ ] Side Panel：无关 Tab · **New find** · 扩展已 reload 到当前 dist

### 首句（clue₁）

- [ ] 提示语只用：「你还记得什么都行。」
- [ ] 录完整首句 → 最小清洗后 UI 提交（真人首句，Agent 可代填 UI **不得改写**）
- [ ] 勾选维度 T/S/G/C/D/R/F；标**主锚**一码
- [ ] 记：邻域是否含 gold · TTE-V（若方便）· Framing 短摘 · taxonomy

### 补句（clue₂）— **本批硬规则**

| clue₁ 结果                          | clue₂                                                       |
| ----------------------------------- | ----------------------------------------------------------- |
| **miss**（库有、邻域无）            | **必做**：问「还能想起别的吗？」；勾选**新增**维度；记邻域₂ |
| **yes**                             | 可选；若做了也勾维度（便于以后）                            |
| **no** / 未检索（如 missing_topic） | 可选；若补句仍无主题，记清楚                                |

- [ ] miss 时：在卡上写明 clue₂ 相对 clue₁ **新增了哪些码**（G/S/C/… 或「无新增」）
- [ ] **禁止**为凑 H2 在看过结果后编「假用途句」冒充自发补句

### 确认

- [ ] `yes` / `miss` / `no` 三选一（维护者主观）
- [ ] `no` 写清原因：未存 / 口语≠目标 / 无主题 / 其它

### 回写暗线（可每 2–3 条一批）

- [ ] 只更新笔记 §3 表 A/B：**会话码、维度、是否 C/G、邻域、clue₂、确认** — **无原文**
- [ ] 独立首句计数：与已有句字面相同 → **不**加算独立首句（仍可算另一 gold 的履约）
