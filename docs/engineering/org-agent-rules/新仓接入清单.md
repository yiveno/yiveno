# 新仓接入清单（Org Agent Rules）

> 用于 **运营 agent / 客服 agent / 其它 Org 仓**。  
> **L0 权威：** [`yiveno/agent-rules`](https://github.com/yiveno/agent-rules)

## 0. 先判定

| 问                                 | 是 →                                                      | 否 →                      |
| ---------------------------------- | --------------------------------------------------------- | ------------------------- |
| 是否 GitHub Org `yiveno` 下的仓？  | 继续                                                      | 仍可 sync，归属段落按实改 |
| 是否与主产品共享同一用户产品契约？ | 考虑 L1 原则包（见盘点 §3）                               | 默认只装 L0 + 自写 L2     |
| 技术栈是否与主产品不同？           | **必须**自写 L2 `project.mdc`，禁止抄 Chrome/MCP 段当装饰 | —                         |
| 是否主产品仓 `yiveno/yiveno`？     | 已 flat sync；只需再 sync 更新 L0，并保持 L2 附录不回膨胀 | 用下方 sync               |

## 1. Sync L0（必选）

```bash
git clone git@github.com:yiveno/agent-rules.git   # 若本地尚无
cd /path/to/agent-rules
./scripts/sync-to-repo.sh /path/to/your-new-repo --templates
```

- [ ] 目标仓 `.cursor/rules/` **平铺**出现 6 个 L0 `.mdc` + `ORG_L0_SYNC.md` + `ORG_L0_SYNC_META.txt`
- [ ] L0 文件约定只读；改 L0 回 `agent-rules` 再 sync
- [ ] **不要**依赖 `shared/` 子目录（Cursor 加载不可靠）
- [ ] 若曾有自写全文 `agent-core` 等与 L0 重复 → sync 后删掉重复全文，只留 L2 附录

## 2. 薄指针与 Brief（必选）

- [ ] 根目录 `AGENTS.md` 已按模板填写（`--templates` 在无现成文件时会写入）
- [ ] `docs/agent/AGENT-TASK-BRIEF.template.md` 可用；按需加 L2 扩展段
- [ ] `.cursor/rules/README.md`：列出 `shared/`（L0）与本仓 L2 文件

## 3. 编写 L2（必选）

- [ ] `.cursor/rules/project.mdc`：**只写本仓**——语言/框架、目录边界、验证命令、产品边界、改动面→文档路径表
- [ ] **禁止**把主产品 Chrome / Side Panel / Recall / IndexedDB / CWS 大段原样粘贴进无关仓
- [ ] （可选）`terminology.mdc` + Glossary
- [ ] （可选）`session-boot.mdc` + `CURRENT`
- [ ] （可选）commit-msg / 破坏性 git hook

## 4. 明确不要从主产品拷的文件

| 主产品文件                               | 原因                                |
| ---------------------------------------- | ----------------------------------- |
| `testing-real-library.mdc`               | 维护者个人真库偏好                  |
| `terminology.mdc` / `session-boot` 内容  | 属主产品                            |
| `project.mdc` 整文件                     | 只借鉴结构                          |
| 主仓顶层与 L0 同名的完整版（含产品示例） | 用 agent-rules 的 `*-core` / 核文件 |

## 5. 冒烟验收

- [ ] 新开会话：agent-core / git-workdir 生效
- [ ] Brief 小改动：报完成不问 commit；行为变更文档同批更新
- [ ] `project.mdc` 验证命令真实可跑
- [ ] shared 内无 Vue/Bun/Chrome/Recall 硬依赖

## 6. 更新 L0 后

```bash
cd /path/to/agent-rules && git pull
./scripts/sync-to-repo.sh /path/to/your-repo
# 在业务仓审 .cursor/rules/shared diff → commit
```
