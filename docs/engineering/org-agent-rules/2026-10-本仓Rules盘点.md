## 3. 可升 L1（产品族可选包）

运营/客服等**默认不装**；主产品或多仓共享同一用户产品契约时可装原则版：

| 原则                           | 来源                                | 说明                                                           |
| ------------------------------ | ----------------------------------- | -------------------------------------------------------------- |
| 禁止内容别名灰名单冒充全量通解 | `project.mdc`                       | 机制 vs 特例表；残差诚实留给字面/通用算法                      |
| 产品面语言 vs 开发者面语言分离 | `project.mdc` + `dev-chinese-plain` | 具体 locale 闭集由各仓钉                                       |
| Normative 权威优先级骨架       | `project.mdc` / `session-boot`      | `开机层 > Glossary > CURRENT > 产品文档 > ADR > project rules` |
| 术语表模式                     | `terminology.mdc`                   | 「唯一权威 Glossary + 必记锚点表」；词条本身不进 L0            |

本阶段**不**落 L1 独立草稿文件（避免过早产品化）；需要时从主仓抽原则版再开包。
