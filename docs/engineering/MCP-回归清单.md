# MCP 回归清单（常驻）

> **用途**：Cursor 每批 MCP 回归的必跑条目，不临场想。**结果写进每批汇报，不写回本文件**（本文件是清单，不是验收记录）。
>
> **对照**：Muse（阿黄）验收清单与本清单对照写，重叠条目在那边标注；关键流程双保险是有意的。

## 前置（执行前必读，不复述）

- MCP 流程（单测 → 构建 → `chrome://extensions` 重载 → UI 路径复现 → 汇报结论）：`project.mdc`「MCP 真机实测」。
- 开页先 `list_pages` 复用已有标签：`mcp-chrome-tab-reuse.mdc`。
- 用日常 Profile + 真实库：`testing-real-library.mdc`；禁止用 `evaluate_script` 直调消息冒充 UI 测试（`project.mdc`）。
- 分工与汇报格式：`collaboration.mdc`「测试分工」。

## 怎么用

1. 每批跑**本批面全部适用条目 + 直接相邻面**的适用条目（相邻 = 共享组件 / 数据 / 入口的面，如 Library 改动相邻 Detail 与 Settings 第三方数据）。
2. 汇报按条目编号逐条写：通过 / 失败 / 不适用 + 原因。失败当场修并重测，重测结果一并写。
3. 条目过时（UI 已改）或缺口（新流程无条目）→ 在汇报里写出来，由 Muse 修清单，不自行改清单。

## Library（库）

| #      | 路径 / 操作                                          | 通过标准                                                                                              |
| ------ | ---------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| LIB-01 | 打开 `library.html`，摘录 tab                        | 已有摘录正常渲染（标题 / 来源 / 时间）；无 raw key；控制台无报错                                      |
| LIB-02 | 摘录「加载更多」（库内摘录 >200 条时；不足则不适用） | 首屏 200 条；点加载更多追加，滚动位置不变                                                             |
| LIB-03 | 书签 tab 树渲染与对齐                                | 树结构与 Chrome 书签一致；已入记忆的行不显示「未进入记忆」                                            |
| LIB-04 | 导入失败面板 / 横幅 + 重试                           | 失败态下：Chrome 树 0 条 → 面板，>0 条 → 横幅；点重试可续跑（失败态可经 storage 注入构造，验证走 UI） |
| LIB-05 | 摘录删除                                             | 删 1 条 → 列表减少 1 条；刷新后仍不在                                                                 |
| LIB-06 | 导出复制 / 下载                                      | 进导出模式选 1 条：复制菜单与下载菜单两项（Markdown / JSON）均可点；下载文件内容与选中条目一致        |
| LIB-07 | 导出菜单不裁切（视觉）                               | 复制 / 下载菜单打开后截图：菜单完整可见，无裁切（F4）                                                 |
| LIB-08 | 书签行打开原文                                       | 点书签行 → 新标签打开对应 URL                                                                         |

## Settings（设置）

| #      | 路径 / 操作                    | 通过标准                                                                            |
| ------ | ------------------------------ | ----------------------------------------------------------------------------------- |
| SET-01 | 打开 `settings.html`，分区渲染 | 8 分区全部渲染为翻译文案，无 raw key（裸 `settings_tab_*` 即失败）                  |
| SET-02 | 账号区登录态                   | 未登录显示登录入口；登录后显示账号与退出；退出后回未登录态                          |
| SET-03 | 云同步开关 + 隐私弹窗          | 首次开同步 → 先弹隐私确认；点取消 → 开关仍 OFF、无云端写入                          |
| SET-04 | 书签导入 / 同步独立            | 导入按钮与同步开关各自独立；同步 OFF 时导入完成不拉新书签；导入状态行数字与实际一致 |
| SET-05 | 暗线同意开关                   | 两个开关（本地学习 / 贡献匿名汇总）各自独立；OFF 时无上传；文案完整无 raw key       |
| SET-06 | 语言切换                       | 切 en / zh_CN → 分区文案即时切换；刷新后保持                                        |
| SET-07 | 快捷键分区                     | 快捷键列表渲染；管理链接可点，落在扩展快捷键管理页                                  |
| SET-08 | 第三方数据状态行               | 未导入 / 已导入 / 失败三种状态文案诚实（失败不说成「尚未导入」）                    |

## Side Panel Recall（侧栏召回）

| #      | 路径 / 操作                                                     | 通过标准                                                              |
| ------ | --------------------------------------------------------------- | --------------------------------------------------------------------- |
| RCL-01 | `sidepanel.html` 当 tab 打开（MCP 只测 panel 逻辑，真开归人工） | composer 可输入；首字输入 `scrollY===0`，底栏不贴边裁切               |
| RCL-02 | 英文 clue 召回                                                  | 输入英文 clue → 返回邻域卡，Top Pick 明确；卡含标题 / 来源 / 打开原文 |
| RCL-03 | no_match 诚实终局                                               | 无匹配 clue → no_match 态，文案诚实，不编造结果                       |
| RCL-04 | 追问与芯片                                                      | need_a_clue 时出现追问 + 可点芯片；点芯片继续召回                     |
| RCL-05 | 多轮会话                                                        | 追问一句 → 结果基于累积线索（排除 / dismiss 生效）；New find 清线程   |
| RCL-06 | 闲聊意图                                                        | 输入闲聊（如问候）→ 自然回复并引回找东西，不当作召回跑空结果          |
| RCL-07 | 结算 / 反馈                                                     | 结果卡确认 / 排除可点，状态有反馈                                     |
| RCL-08 | i18n                                                            | 切换语言后 Recall 文案无 raw key                                      |

## Detail（详情页）

| ------ | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |

| DET-06 | 三态空态                            | 无 id / 假 id / 书签 id 各显示 missing_id / not_found / wrong_type 对应文案，无 raw key；书签 wrong_type 显示打开书签链接 |
