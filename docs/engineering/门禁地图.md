## 重复关系（勿删）

- **CI `knip`（每次 PR/main）** 与 **`knip.yml`（每周一 02:00 UTC）** 都跑全仓 knip：前者拦合入，后者定时巡检，防「长期未合入路径」静默堆积。**保留两套。**
- **CI `test:run`** 与显式 **`test:must`** 分计：must 防 eval 目录搬走后「0 tests 假绿」。
