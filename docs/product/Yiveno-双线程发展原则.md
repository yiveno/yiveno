# Yiveno 双线程发展原则

> **地位：** 长期发展框架的**权威正文**。产品文档 §0.1.2 为短锚；工程侧「环境反馈 / 受控适应」见 [`Yiveno-环境反馈驱动进化-原则.md`](./Yiveno-环境反馈驱动进化-原则.md)（**子集**，不得与本文抢权重）。  
> **冲突时：** 明线行为契约仍以产品文档 §0–§7 为准；本文定**双线程使命与设计纪律**。  
> **不是：** 已上线「研究系统」的事实声明，也不是对外 slogan。

---

## 0. 一句话

Yiveno 同时承载两条**相互促进、但不互相替代**的发展线程：明线持续改善找东西体验；暗线通过产品实践逼近人类记忆与信息提取机制。二者共享真实使用，KPI 与话术不得混为一谈。

**Yiveno 既是探索人脑记忆机制的实践，也是让这份探索持续创造真实用户价值的产品。**

---

## 1. 双线程架构

### 1.1 明线：用户价值线程

用户看得见的产品。

```text
模糊线索 → 理解需求 → 检索个人信息 → 返回有用邻域 → 更快找到目标
```

| 项                     | 内容                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------------ |
| **使命**               | 帮助用户从个人信息中找想要的东西；越来越准确、快速、省力（对内勿用「越来越聪明」作主表述，以免滑向助理叙事） |
| **衡量**               | 召回质量、检索耗时、操作成本、任务完成率、使用体验（对齐 §5.9 / Outcome / TTE 等）                           |
| **用户是否要感知研究** | 否；用户只需获得更好用的找                                                                                   |

### 1.2 暗线：记忆探索线程

用户不一定直接感知的研究与学习系统。

```text
观察真实检索 → 分析记忆与提取现象 → 形成假设 → 设计验证 → 更新认知 → 改进检索机制
```

| 项             | 内容                                                               |
| -------------- | ------------------------------------------------------------------ |
| **使命**       | 借助真实使用，逼近记忆形成、组织、遗忘与提取的机制；积累可检验证据 |
| **衡量**       | 有效证据积累、假设验证程度、失败原因识别、对未知问题的解释能力     |
| **科学地平线** | 「完全搞懂人脑」可能一辈子达不到；可工作状态是**不断接近**         |

### 1.3 共享与分离

- **共享：** 真实使用场景与由此产生的信息，可同时服务两条线程。
- **分离：** 明线追求对用户有效；暗线追求对记忆机制有更可靠的认识。
- **一次改进可只满足其一：**
  - **仅明线**（如纯关键词工程提升体验、无新记忆科学发现）→ **仍算产品成功**。
  - **仅暗线且损体验** → **不得**为研究直接推给用户主路径；改走离线实验 / 研究记录。
  - **双赢** → 优先。

### 1.4 三者循环（职责不同）

| 角色             | 职责                                   |
| ---------------- | -------------------------------------- |
| **维护者（你）** | 提出问题、判断证据、选择值得追求的方向 |
| **Yiveno**       | 为用户提供服务，并在合理边界内学习改进 |
| **真实世界**     | 提供不能被理论完全替代的反馈           |

不需要先彻底理解人脑才能做出有价值的 Yiveno；需要的是：每一轮对记忆机制的理解，都有机会转化为**可验证**的产品进步。

## 2. 设计检查：五问（默认门禁）

暗线进入业务的方式是**固定设计检查**，不是单独做一个「人脑研究」用户模块。

### 2.1 何时必过 / 何时 N/A

| 改动类型                                                              | 五问                           |
| --------------------------------------------------------------------- | ------------------------------ |
| **方案 / 新能力**（产品行为、契约、新交互、新检索策略、新反馈通道等） | **必过**                       |
| **纯修回归**（修 bug、对齐已有 Normative、无新假设）                  | 可写 **N/A**（Brief 标明即可） |

### 2.2 五问

**01 · 用户问题是什么？**  
解决哪一种真实的找困难？是否值得解决？

**02 · 它能让我们观察到什么？**  
行为能否帮助理解线索形成、记忆提取、遗忘、注意力或信息组织？还是只能证明「功能被点了」？

**03 · 我们可以检验什么假设？**  
提出**可被证伪**的假设；禁止事后编造解释冒充研究。

**04 · 能否用这些证据改善产品？**  
若某类线索更适合某类检索，能否改进候选生成、排序、理解或策略？

**05 · 怎样知道结论可靠？**  
替代解释、相关 vs 因果、样本偏差、独立评估（must / 金标 / §5.9 类）。

### 2.3 诚实出口（枚举）

1. **双赢** — 明线价值 + 暗线证据/假设
2. **仅明线** — 工程或体验成功；不冒充研究进展
3. **仅暗线** — 默认研究记录 / 离线验证；不默认进用户主路径

若无合理研究价值，或取证成本远超收益 → **正常开发，不为暗线强行加采集**。

---

## 3. 四条边界（不可轻易牺牲）

1. **不为研究损害体验。** 用户首先获得真正有用的产品。
2. **不把用户当未经告知的实验对象。** 必要性、透明度、授权、隐私；能本地处理的证据不必默认上传。
3. **不把行为数据直接当作记忆规律。** 点击、停留、改 clue 只是观测信号；Yiveno 看到的是特定数字环境中的提取行为，不是人脑全机制读数。
4. **不要求每项功能同时完成双目标。** 双线程是长期战略，不是每个需求的双重 KPI。

另：**命题先验**（§0.1.0）不被暗线话术替代；放弃率↓ 不冒充 §5.9。

暗线「有没有在做」用**独立研究记录**证明，不用功能堆砌或对外叙事证明。

| 项       | 约定                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| **位置** | [`docs/archive/research/dual-thread-notes/`](../archive/research/dual-thread-notes/) |
| **模板** | 同目录 `_TEMPLATE.md`                                                                |
| **必含** | 假设、数据来源、替代解释、验证方法与结果、置信度                                     |
| **禁止** | commit 私人遥测原文、完整私人库导出、可识别用户内容；事后编故事冒充事先假设          |

工程侧受控适应、Outcome、eval 等细节见环境反馈原则文档（子集）与 §7.2 / §5.9。

## 6. 示例（自然语言线索 · 说明用）

**明线：** 如何理解 clue、召回、控延迟、减无效结果。

**暗线可追问：** 用户更常依赖主题 / 用途 / 情境 / 含义？哪类补充最可能命中？连续改写是记忆渐清还是系统未懂？记得「为何保存」忘了「叫什么」时哪条路径更有效？

转化为可验证比较（尽量控制其它变量）后：支持则改机制；不支持则修正认知——**同样有价值**。  
须谨慎：界面、经验、库规模、算法本身会塑造行为；不得仅凭日志宣称普遍人脑规律。
