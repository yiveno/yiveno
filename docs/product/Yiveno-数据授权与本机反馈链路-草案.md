# Yiveno · 数据授权与本机反馈链路（细节权威）

> **地位：** 产品文档 **§5.5.1 A/B/C** 的细节与本机链路对照。冲突时以产品文档 + `/privacy` 为准。  
> **已晋升：** A/B/C 短锚 · `/privacy` §2.8 · Settings 隐私 bullet · **清除本机适应信号** · **暂停 Outcome 软调**。  
> **仍未做：** B/C 上云管道、三开关「帮助改善」总闸、暗线写成已上线自进化。  
> **禁止对外：** 「帮助改善 = 已在云端学习你的习惯」「越用越懂你 → 一定找得到」。

---

## 0. 为何需要本文

常见「帮助我们改善产品」开关，把**多种数据用途**揉成一把刀。Yiveno 必须拆开：

| 易混                      | 正解                                                                       |
| ------------------------- | -------------------------------------------------------------------------- |
| 本机从打开/Outcome 学排序 | **服务交付的一部分**（个人库上的适应），不是「捐数据给公司」               |
| 匿名全体产品统计          | **产品研发观测**；今日**默认不收**；将来须**单独 opt-in**                  |
| 关 AI 功能                | 停**推理调用**（理解/enrichment），≠ 授权/撤销「用你的内容做质量评估留存」 |
| 云同步                    | 仅摘录换机（ADR-017），**不是**改善产品授权                                |

一句话：**个体本机适应 ≠ 全体上云学习 ≠ AI 内容留存评估。**

## 1. 三层授权口径（Normative 短锚见产品文档）

| 层                          | 产品名（en）                  | 数据范围                                                       | 默认                          | 关后核心找东西 |
| --------------------------- | ----------------------------- | -------------------------------------------------------------- | ----------------------------- | -------------- |
| **A · 本机个人适应**        | On-device recall adaptation   | 本机：打开/dismiss、§7.2 Outcome 对、条目行为计数、本机 TTE 环 | **开**（披露）                | **必须仍可用** |
| **B · 匿名产品改进**        | Anonymous product improvement | 经处理的聚合/诊断                                              | **关**（无上云管道）          | 无影响         |
| **C · AI 质量评估（内容）** | AI quality review (content)   | AI 请求/反馈及相关内容留存                                     | **关**；≠ `aiFeaturesEnabled` | 无影响         |

**与现有开关：** 云同步 / `aiFeaturesEnabled` / MCP / 隐私 ack / 卸载反馈 — 均不得冒充另一层。

**控制面（A）：** Settings → 数据与隐私 → 分组「本机 Recall 适应」：**Outcome 软调开关**（暂停）+ **清除本机 Recall 适应信号**（`CLEAR_LOCAL_RECALL_ADAPTATION`）；清空本机记忆时**一并**清缓冲。条目 `openCount` 仅随清库删除。  
**UI 铁律：** 披露/MCP/政策与搬进/带走/本机适应/删除同页；**禁止** Meta 式「帮助改进 AI」总开关；B/C 口径见披露摘要 + `/privacy`。
