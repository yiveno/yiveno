# Yiveno 国际化 · CN-NA（Internationalization Contract）

> **Normative · 当前有效基线（冻结）**  
> 本文不是「翻译清单」，而是 **国际化架构契约**：钉死独立轴、市场定义、已落地、残差与禁止擅自扩面。  
> **原则：** 能力边界由经验证的产品需求推动，不由「技术上能做」推动。  
> **禁止**把单一 `locale` 当成地区 / 货币 / Recall 质量 / 域名 / 邮件的总开关。

## 0. 三层覆盖（勿合并成「已支持某市场」）

| 层               | 含义                         | CN-NA 现状（诚实）                                             |
| ---------------- | ---------------------------- | -------------------------------------------------------------- |
| **市场覆盖**     | 用户能否访问、注册、使用入口 | 大陆 + 美国路径可访问；`.com` / `.cn` 软分流                   |
| **产品能力覆盖** | 核心功能是否达该语言质量门槛 | **Recall 仍以美式英语线索为主**；中文 UI ≠ 中文线索就绪        |
| **商业覆盖**     | 购买 / 付款 / 售后是否完整   | 标价 USD；Adaptive 扣款；登录 Email+Google/MS；事务邮件英-only |

**中国大陆定位（Normative）：** 当前 = **可访问的体验 / 验证市场**（UI 中文已接线）；**不是**「核心 Recall 中文质量已达标的正式对等商业市场」。未达产品能力覆盖前，禁止对外写成「已全面支持中国市场」。

## 1. 「北美」商业范围（精确化）

「CN-NA」中的 **北美 = 美国优先**，不是整块北美自由贸易区的商业承诺。

| 地区       | 本基线                                                                            |
| ---------- | --------------------------------------------------------------------------------- |
| **美国**   | **正式目标市场**（en-US UI 习惯、USD 锚点、英主 listing、美式英语 Recall 主验证） |
| **加拿大** | 技术上可访问；**商业支持程度待定**（未承诺 fr-CA / CAD 本地价 / 本地合规专版）    |
| **墨西哥** | **不纳入**本波市场                                                                |

## 2. 独立轴（勿混为一谈）

| 轴                  | CN-NA 决策                                                               |
| ------------------- | ------------------------------------------------------------------------ |
| **UI 语言**         | `en`（美式） / `zh_CN`（简体）；默认 `system`；可覆盖并持久化            |
| **地区域名**        | `yiveno.com` ↔ `yiveno.cn` 软跳；**≠** 锁语言                            |
| **货币展示**        | 标价 / 锚点 **USD**；扣款可 Adaptive 本地币（收据本地币 ≠ 人民币套餐价） |
| **Recall 线索质量** | **美式英语主路径**；另见 §3                                              |
| **语音识别语言**    | **独立轴**；当前默认跟 UI locale，**禁止**架构上永久绑死（见 §5.2）      |
| **文字方向**        | 仅 LTR；**不做 RTL**                                                     |
| **法律正文**        | 同 URL 双语；**冲突以英文版为准**                                        |
| **事务邮件**        | OTP / Pro welcome 等 **保持英文**（残差）                                |
| **商店 listing**    | CWS / Edge **英主**；包内 `_locales` 含 zh_CN                            |
| **时区**            | 浏览器本地；不由 UI 语言决定                                             |
| **数据治理 / 跨境** | **不在本文扩写**；另立规范（见 §7）                                      |

### 2.1 域名 GEO 优先级（已实现）

权威实现：`website/src/geo/resolve-geo-domain-redirect.ts`。

```text
显式查询 ?geo_domain=（含 stay）
  → 持久 Cookie 偏好（com / cn / stay）
  → 首次/无偏好时 CF country 建议（仅 CN→.cn，其它有码→.com）
  → 无国家码 / 爬虫 / 预览域 / .cn 未 live：不跳
```

地区识别只做**初始建议**；**不得**用 IP 持续覆盖用户主动选择（query / Cookie）。禁止两域无偏好时来回互踢成环。显示语言**不在**此函数处理。

## 3. UI 国际化 ≠ AI / 检索能力国际化

| 能力                   | 问题                          | CN-NA                                  |
| ---------------------- | ----------------------------- | -------------------------------------- |
| **UI Language**        | 界面用什么语言                | en / zh_CN **已接线**                  |
| **NLU Language**       | 模型能否理解该语言线索        | **英主**；中文非 P0                    |
| **Retrieval Language** | 索引/召回对该语言内容是否够用 | **英主验证**；禁止用 UI 中文冒充已就绪 |

**铁律：** 中文 UI ≠ 中文线索已就绪。三者必须**分计验收**。

## 5. 边界澄清（审查修订）

### 5.1 Detail 导出时间：人读 vs 机器

| 面                     | 格式                                                            | 说明                                         |
| ---------------------- | --------------------------------------------------------------- | -------------------------------------------- |
| **机器契约**           | ISO 8601（如 `exportedAt` / item `createdAt` 的 datetime 字段） | JSON 包等；**真正的交换格式**                |
| **人读 Markdown 正文** | 固定 `en-US` `toLocaleString` 展示                              | 面向人的导出可读性；**不是**稳定数据交换契约 |

禁止把「Markdown 里写死英文日期」说成「交换格式」。改人读展示 locale 须另开 Brief；改机器字段不得离开 ISO。

### 5.2 语音识别 vs UI locale

- **模型：** `speechLocale` 与 `uiLocale` 为两轴；理想形状含可选独立偏好。
- **现状：** `speechRecognitionLangForUiLocale` **默认** `en`→`en-US`、`zh_CN`→`zh-CN`。
- **允许：** 近期继续默认跟随，**不**加设置 UI。
- **禁止：** 在类型 / 存储层把二者焊成不可拆的同一字段；日后覆盖不得先拆库大迁移。

### 5.3 能力矩阵（摘要）

| 能力        | 美国                       | 中国大陆                       |
| ----------- | -------------------------- | ------------------------------ |
| UI          | en                         | zh_CN                          |
| 核心 Recall | 美式英语主路径             | 中文质量**未**作对等承诺       |
| 账户        | Email / Google / Microsoft | 同左（第三方在当地可用性另计） |
| 定价锚点    | USD                        | USD（+ `.cn` 换汇诚实旁注）    |
| 事务邮件    | 英文                       | 英文                           |
| 商业适配    | 主路径                     | **有限**（体验/验证优先）      |
