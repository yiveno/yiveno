# ADR-003: 交付邻域集合；Top1 = 建议，非神谕

- **状态：** 已接受
- **日期：** 2026-08-15（2026-08 定位纠偏）
- **决策者：** 产品 Normative

## 背景

「每次押中那一条」的承诺不可验证、不可辩护，且与模糊线索现实不符。竞品与用户对「找东西」的预期是**相关集合**，不是终审答案。

## 决定

1. Recall 交付 = **按符合度排序的邻域**（ranked neighborhood）；告知总数 N；首屏默认 ≤5，可 Show more。
2. **`top_pick`** = 建议首项，**不是**正确答案或神谕。
3. 会话成功 = 用户在邻域（含续展）拿到想要的；Top1 命中是 delight，**非唯一 KPI**。
4. `no_match` = 诚实终局；禁止假装命中或偏好建档闲聊。

## 后果

**必须：**

- UI / NLG / eval 以邻域命中为主尺；头名单独记 delight。
- 空结果导向 Capture / 追问（`need_a_clue`），不开放助理人设。

**禁止：**

- 对外文案承诺「永远押中」「置信百分比神谕」。
- 因目标在 Top2/3 判产品失败而隐藏次优结果。
