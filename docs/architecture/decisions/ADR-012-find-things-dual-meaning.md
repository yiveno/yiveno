# ADR-012: Find things 一语双关为后手；终局壁垒在私有增量与习惯

- **状态：** 已接受
- **日期：** 2026-09-11（同日修订：双关=后手非固定路线；补斧正纪律）
- **决策者：** 产品 Normative

## 背景

「那个找东西的 / find things」既是锋利品类标签，也容易被读成「又一个 AI Search」。相册、网盘、浏览器、系统助手会把「口语找已存内容」做成基础能力——**内容层检索会商品化**，不宜当长期护城河押注。

英语 _things_（与中文「东西」）日常可不限于书签/文件。品牌上留双关空间有利；但若把「前期工具 → 后期记忆翻牌」写成**必须走完的路线图**，会把优雅叙事误当成已验证战略。

## 决定

1. **定位句不变：** 对外主心智始终是 **那个找东西的 / find things**（及早期履约句 _Find what you saved_）。不另起第二品类 slogan 替代主句。
2. **things 一语双关 = 品牌后手（Normative）：**
   - **表层（大众默认 · 当前入口）：** 书签、摘录、文件、视频等可存可找的对象。
   - **深层（可选外延）：** 附着个人意义的记忆对象——对话、回忆、喜好等——**须仍落在用户主动附着的痕迹上**。
   - **非固定路线：** 双关与翻牌是**留的后手**，是否启用、何时加厚外延，**视具体发展（痕迹厚度、留存、§5.9、竞争格局）再定**；不得写成必须兑现的 Phase 承诺。
3. **终局壁垒（Normative · 斧正）：** 不是「从 Search 升级成 Memory」的品类跳跃，而是用户**不愿迁走的私有增量 + 找东西习惯 + 信任**。记忆层若出现，只是这层资产的**产品表达**，不是形而上学豁免，也不是「做记忆就不会被 AI 浪潮卷进去」。
4. **护城河分层（仍成立）：** 内容语义（图里有什么）可商品化；记忆语义（对你意味着什么）难复制——但**个人记忆赛道本身**也会被相册/系统/Agent 挤压。范围仍收在**主动 Capture、可验证的个人痕迹**。
5. **预留品牌翻牌句（Non-normative · 未启用 · 后手）：** _Why should things just be things?_ ——仅当外延**已可交付**且不撕碎工具心智时，才可升对外主句；无交付则双关只作**对内战略语言**。**当前不得**写进官网/扩展主 slogan。

## 斧正纪律（2026-09-11 过审 · 勿与上文重复叙述）

| 纪律                    | 含义                                                                                                                                          |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **双关 ≠ 产品路径**     | 语言学红利是事后解释权，不是前期可少做履约的许可证；用户听到 find things 多数仍落成「存过的内容」。                                           |
| **工具期就要攒燃料**    | 若前期只养成乱扔 URL，库厚但记忆语义稀薄——翻牌时无牌可翻。摘录/附注须在工具期就是主角（与 §0.1.1 资产表一致，此处只钉「为后手攒燃料」动机）。 |
| **传感器天花板**        | Chrome 扩展拿不到系统相册人脸、通讯录、完整行程；现实记忆层 = **浏览中附着痕迹 + 可验证来源**，不是人生传记引擎。                             |
| **终局叙事 ≠ 当前可糊** | 「内容检索非长期壁垒」**不得**合理化召回质量松懈；没过 §5.9 / 邻域爽点，谈不上任何后手。                                                      |
| **翻牌不是存活条件**    | 若后手永不启用：只要邻域找东西极爽 + 本地可信 + 私有增量持续，Yiveno 仍可成立。双关失败 ≠ 产品命题失败。                                      |

## 后果

**必须：**

- 前期/当前文案保持工具履约；口语可保留 _things_ 宽语义，**禁止**说死成「仅文件/书签搜索」，也**禁止**把「后期必翻牌」写进对外承诺或 sprint 必达。
- 持续加厚个人增量（摘录/附注/Outcome）——既服务当前找东西，也为**可选**后手留燃料。
- 任何外延仍服从：主动 Capture、邻域非神谕、LLM 不碰数据平面、禁止生活小助手。

**禁止：**

- 用「通用 AI 找东西更准」当长期战略；用内容识别冒充记忆语义。
- 无痕迹/无交付时摊牌「人生记忆产品」或启用翻牌句。
- 把 ADR 里的后手写成不可变更的路线图，或用终局诗学替代 §5.9 验收。

## 补充（2026-11-01 · 产品哲学 · 不改本 ADR 决定）

产品文档 §0.1 增补「产品哲学与愿景边界」：人机认知协同（机记人想；AI=接口）；愿景可大、**当前履约面仍为已存痕迹高置信邻域**。与本 ADR「终局叙事 ≠ 可糊召回 / 翻牌非存活条件」同向——哲学与远景**不得**替代本 ADR 的对外定位句与斧正纪律。术语表 §1 同步「产品哲学 / 愿景 vs 履约 / 先锋入口」。
