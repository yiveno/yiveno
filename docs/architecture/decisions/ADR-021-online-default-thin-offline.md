# ADR-021: 在线默认 · 离线仅薄适配

- **状态：** 已接受
- **日期：** 2026-11-06
- **决策者：** 维护者（2026-11-06 明示：业务建立在网络正常前提下；离线不应投入当前这么多）
- **前置：** ADR-001（Side Panel 主壳）· ADR-007（Omnibox 本机快跳）· ADR-010（理解默认 LLM）· 产品文档 §0.1
- **产品短锚：** [`Yiveno-产品文档-v4.0.md`](../../product/Yiveno-产品文档-v4.0.md) §0.1.4

## 背景

Yiveno 当前履约面是：浏览器里主动 Capture 的痕迹 → 口语 clue → 高置信邻域 → 打开原文。主资产多为**网上的那一页**（书签 URL / 摘录来源页）。

若把「完全断网仍能爽用找东西」当架构主约束，会出现：

1. **体验陷阱：** 用户已开浏览器却断网时，即便邻域正确，多数目标 URL 也打不开——为断网找开放页优化性价比极低。
2. **投入错位：** 离线壳、双轨降级、规则「离线产品化」叙事易挤占 §5.9 / 在线听懂 / 结果卡等主线。
3. **概念混淆：** 「LLM/API 不可用」「弱网 12s 超时」「`navigator.onLine === false`」被揉成同一种「离线」，导致错误排期。

维护者裁决：**业务默认在线；离线只做基本适配。**

## 决定

### 1. 产品先验（接受后勿用离线叙事扩 sprint）

| 项           | 决定                                                                              |
| ------------ | --------------------------------------------------------------------------------- |
| **履约默认** | 用户网络可用；托管理解 / embed / 打开原文均按在线设计                             |
| **离线**     | **薄适配**：不空等云端、诚实提示本机模式、本机 IDB 仍可读（含摘录卡扫读已存正文） |
| **禁止**     | 把「完全离线找开放页」当主体验或架构主约束；为离线堆第二套理解/检索产品           |

### 2. 与既有分轨的关系（不推翻）

| 能力                            | 在本 ADR 下的读法                                                                                                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **ADR-007 Omnibox**             | 保留：**本机快跳**（延迟 / 壳装不下 / 无 LLM·向量成本）。主卖点是快与本地，**不是**「离线产品」。命名里的 offline 指 lookup 轨不调云理解，不等于 Yiveno 离线优先。       |
| **规则 `parseRecallClue`**      | 保留三角色：**闭集槽位接地** + **Omnibox lexical** + **降级垫片**（无模型/失败/断网 omit）。**不是**离线主 NLU，也不是第二套口语听懂引擎；禁止为「更懂」无限扩 surface。 |
| **Side Panel 离线壳（§7.0）**   | 保留薄信号 + omit 线索 LLM；**禁止**再加深为整壳换肤、离线专属召回产品化。                                                                                               |
| **弱网 12s → `rules_fallback`** | 属**在线弱网 / 配额失败**，继续投入诚实降级；与「断网找网页」分计。                                                                                                      |

### 3. 排期与重构纪律

- 新方案五问 / Brief：若收益写的是「断网也能找」，默认 **Out of scope**，除非维护者点名薄适配 bug。
- 存量代码：可逐步标清 / 合并纯为「离线优先」而冗余分叉的路径；**须单独 Brief**，禁止借本 ADR 顺手大重构无关模块。

## 后果

- **正：** 主线精力回到在线听懂与找得到；减少假需求。
- **负：** 极端断网用户打开 URL 仍失败（接受）；离线壳不再加码。
- **文档：** 产品 §0.1.4 + CURRENT 冻结列表同步；§7.0 离线条注明「薄适配」。
