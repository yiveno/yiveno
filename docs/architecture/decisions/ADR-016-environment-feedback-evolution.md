# ADR-016 · 双线程：明线用户价值 · 暗线记忆探索 · 反馈非真理

## 状态

**已接受**（2026-10-09；同日升格双线程权威正文）

## 背景

维护者将 Yiveno 定为**双线程**长期实践：明线改善找回体验；暗线借助真实使用逼近人类记忆与提取机制。权威正文见 [`Yiveno-双线程发展原则.md`](../../product/Yiveno-双线程发展原则.md)。工程上，证据驱动的手段适应见环境反馈子集文档。本 ADR 只钉**不可重议的约束**。

## 决策

0. **双线程并存、不互相替代。**  
   明线 = 用户找回价值；暗线 = 记忆机制探索。共享真实使用；KPI/话术分离。仅明线的工程改进仍算产品成功；仅暗线且损体验者不得默认进用户主路径。

1. **设计五问为方案/新能力默认门禁；纯修回归可 N/A。**  
   全文见双线程原则 §2。出口：双赢 / 仅明线 / 仅暗线（离线+研究记录）。

2. **暗线正式载体 = 研究记录（模板 + `dual-thread-notes/`）；私人数据不进仓。**

3. **目标相对稳定，手段根据证据适应**（工程子集）。系统不得仅凭短期行为指标改产品目标或成功定义。

4. **环境反馈 = 证据，≠ 客观真理；行为数据 ≠ 人脑规律。**  
   与 §7.2 explore≠settle / `unknown` 一致。

5. **适应三层授权：** 参数/策略可探索（须可观测、可验证、可回退、独立评估）；**目标自主改变禁止默认授权。**

6. **四条边界：** 不为研究损体验；不把用户当未告知实验对象；不把行为直接当记忆定律；不要求每项双重 KPI。

7. **与命题先验同向；隐私与 ADR-007 Omnibox 天花板继承。**  
   不得以「懂人类 / 双线程 / 自我进化」放松 §5.9 或灰名单捷径（ADR-005）。

## 后果

- Agent 方案任务：Brief 填五问（或 N/A）；暗线进展看研究笔记，不看功能堆砌。
- 环境反馈 / R5 自适应实现服从双线程边界；未满足不得标「已懂人类」或「已上线自适应」。
- 文档层次：双线程原则 > §0.1.2 短锚 > 本 ADR；环境反馈文档为子集。

## 拒绝的替代

| 方案                             | 拒绝理由                            |
| -------------------------------- | ----------------------------------- |
| 暗线做成用户可见「脑科学」产品面 | 破坏明线心智；研究叙事不进主 slogan |
| 每项需求强制双重 KPI             | 双线程是长期战略，非每个 ticket     |
| 点击率直接当记忆规律 / 优化目标  | 混淆行为与机制；污染已由 §7.2 纠正  |
| 为取证默认上传全文私人库         | 违反隐私边界                        |
