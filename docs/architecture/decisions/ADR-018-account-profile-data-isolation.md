# ADR-018: Account vs Profile 数据隔离 · 权益两档 · 登录迁移门闸

- **状态：** 已接受（**实现已接线**——登录迁移门闸 + 退出释放回本地档 / Pro flush；静默 absorb 已拆除）
- **日期：** 2026-10-15
- **决策者：** 产品 Normative

## 背景

真机暴露：登录期间灌库/摘录写在 `accountId` 桶，退出后 `ownerId` 回到 `localProfileId` → Recall 假空库；登录又静默 `absorbLocalProfileIntoAccount`，共享电脑上 B 登录可能吞掉 A 的本机库。根因不是单点 bug，而是未钉死：

1. **哪些数据跟 Chrome Profile，哪些跟 Yiveno 账号；**
2. **未登录 / 登录 Free / Pro 的权益差到底在哪；**
3. **本机已有摘录遇到新登录时如何归属。**

ADR-017 已钉云同步面仅摘录、书签不上云。本 ADR 钉 **身份平面、权益、登录门闸、退出默认**。

## 决定

### 1. 权益两档（未登录 ≟ 登录 Free 的本机能力）

| 档                                    | 能力                                                                                                                                                                      |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **本机档**（未登录 **或** 登录 Free） | 扩展下载即用：Chrome 书签灌库、**摘录 Capture**、本机 Recall（书签与摘录同等可检）。**登录 Free 不额外解锁本机能力**——账号主要是**凭证**（订阅记录、升/降 Pro、账户页）。 |
| **Pro**                               | 之上增加：**摘录（同步面）上云与换机可见**；准实时 / 退出前 `flush_then_keep`（已接线）；更大托管 LLM / embed 配额等既有 Pro 项。                                         |

- **Pro 到期** → 能力回到本机档；账号凭证保留（可查看订阅记录等）。
- **召回质量**仍不分 Free/Pro（与既有 Normative 一致）；Pro 卖的是 **换机/云镜像**，不是「更好找」。
- **托管 LLM：** 本机划存/找回不因「未登录」关闭；云侧计量路径可仍要求登录 Bearer（防滥用），**不得**把「能 Capture 摘录」做成必须登录。细则以产品文档配额表为准。

### 2. 数据归属（处理生命周期 ≠ Recall 权重）

| 数据                                                   | 归属                                             | 云同步（ADR-017） | 普通退出登录                                   |
| ------------------------------------------------------ | ------------------------------------------------ | ----------------- | ---------------------------------------------- |
| **书签壳**（Chrome 灌库 / 本机第三方 bookmark Memory） | **Chrome Profile / 本机**                        | 否                | **保留**                                       |
| **摘录** `text_excerpt`（及同步面字段）                | **本机工作库**；经迁移门闸后可归属某 `accountId` | **仅 Pro**        | **默认保留**（继续本机档使用）                 |
| **书签附注** `clues.note`                              | 随工作库；跨设备若上云须另案（不得整棵书签上云） | 见 ADR-017        | 默认保留                                       |
| **账号凭证 / 同步态 / 云副本**                         | **Account**                                      | —                 | 清除本机 session/binding；云侧按同步与删号规则 |

换账号 **≠** 合并家产。共享 Profile 上的 Chrome 书签树是物理共用；产品须诚实，不假装按「人」切开书签林。

### 3. 登录迁移门闸（禁止静默 absorb）

登录成功后，若本机存在 **不属于当前 `accountId` 的摘录**（含未登录 `localProfile` 桶、或其它账号残留桶中的摘录）：

**必须弹窗**（美式英语），用户显式三选一：

1. **Import into this account** — 将摘录（同步面）归属当前账号；书签壳不导入账号云语义。
2. **Export** — Backup 后，用户可再确认是否删除未导入副本（不得留下「既不导入又不处理」的糊态）。
3. **Delete** — 丢弃本机这批未归属摘录，不进入当前账号。

- 本机无此类摘录 / 已全属当前账号 → 不弹窗。
- **禁止** `absorbLocalProfileIntoAccount` 式静默 remap。
- 导入只解决归属；**真上云仍须 Pro + 同步**（及隐私 ack）。
- 云上已有摘录时，开同步后的对齐仍按 ADR-017 摘录并集规则；门闸文案可提示。

### 4. 退出与被挤掉（默认留工作库）

| 动作                            | 行为                                                                                          |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| **Free / 未开同步退出**         | 清凭证；**本机工作库保留**                                                                    |
| **Pro 退出**                    | **先同步 flush**（失败则明示：重试 / 仍退出并告知云可能落后）；清凭证；**本机工作库默认保留** |
| **被挤掉**                      | 尽力 flush；清凭证；**本机工作库保留**（本机变为离线本机档）                                  |
| **显式清除本机记忆 / 删除账号** | 按 Settings「数据」强确认路径；与普通退出分开                                                 |

普通退出 **不再** 以「清本机账号桶」为默认三选一主路径；若保留「退出时顺便清除本机」须为显式可选项且二次确认。

### 5. 与 ADR-017 的关系

- 云同步面仍仅 `text_excerpt`；书签不上云。
- 本 ADR 解释 **谁在何种权益下写摘录、登录如何归属、退出是否留库**；不改变「书签林不进云并集」。

## 后果

**必须（已落地）：**

- 产品文档 §5.1 / 账户与同步 Normative 按本 ADR 改写；废弃「登录即静默归并」表述。
- `GET_LOGIN_MIGRATION_STATUS` / `RESOLVE_LOGIN_MIGRATION` + Side Panel / Settings 门闸 UI；拆除静默 absorb。
- 退出 `keep_local` 释放账号库→本地档；Pro `flush_then_keep`；被挤掉 / 官网 sign-out handoff 同释放。
- 设置/隐私文案：未登录可划存；Free 登录不增加本机能力；Pro = 摘录换机。

**禁止：**

- 登录静默把本机摘录并进当前账号。
- 用「退出保留记忆」文案掩盖 Recall 扫错 owner 的隐身空库。
- 将「能 Capture」做成必须登录或必须 Pro。

## 拒绝的替代

| 方案                           | 为何不选                                     |
| ------------------------------ | -------------------------------------------- |
| 摘录必须 Pro                   | 伤害下载即用与私有增量积累；定价过激         |
| 未登录不可摘录、登录 Free 才可 | 与「未登录≟Free 权益」冲突；多一套无必要门禁 |
| 退出默认清本机账号数据         | 与本机档连续性冲突；普通登出不应砸工作库     |
| 登录静默 absorb                | 共享电脑串库                                 |
