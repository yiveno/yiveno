# ADR-018: Account vs Profile 数据隔离 · 权益两档 · 登录迁移门闸

- **状态：** 已接受（**实现已接线**——登录迁移门闸 + 退出清账号桶；静默 absorb 已拆除）
- **日期：** 2026-10-15
- **决策者：** 产品 Normative
- **修订：** 2026-10-15 — 退出口径 A：清本机账号痕迹；无主摘录 = 仅未登录创造；同日再修订：官网/扩展退出解耦（各退各的）

## 背景

真机暴露：登录期间灌库/摘录写在 `accountId` 桶，退出若 remap 进 `localProfileId` → 再登录门闸误把「刚退出的工作库」当无主；登录又曾静默 `absorbLocalProfileIntoAccount`，共享电脑上 B 登录可能吞掉 A 的本机库。根因不是单点 bug，而是未钉死：

1. **哪些数据跟 Chrome Profile，哪些跟 Yiveno 账号；**
2. **未登录 / 登录 Free / Pro 的权益差到底在哪；**
3. **本机已有摘录遇到新登录时如何归属；**
4. **退出后本机还该留下谁的痕迹。**

ADR-017 已钉云同步面仅摘录、书签不上云。本 ADR 钉 **身份平面、权益、登录门闸、退出默认**。

## 决定

### 1. 权益两档（未登录 ≟ 登录 Free 的本机能力）

| 档                                    | 能力                                                                                                                                                                      |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **本机档**（未登录 **或** 登录 Free） | 扩展下载即用：Chrome 书签灌库、**摘录 Capture**、本机 Recall（书签与摘录同等可检）。**登录 Free 不额外解锁本机能力**——账号主要是**凭证**（订阅记录、升/降 Pro、账户页）。 |
| **Pro**                               | 之上增加：**摘录（同步面）上云与换机可见**；准实时 / 退出前 `flush_then_keep`（已接线）；更大托管 LLM / embed 配额等既有 Pro 项。                                         |

- **Pro 到期** → 能力回到本机档；账号凭证保留（可查看订阅记录等）。
- **召回质量**仍不分 Free/Pro（与既有 Normative 一致）；Pro 卖的是 **换机/云镜像**，不是「更好找」。
- **托管 LLM：** 本机划存/找东西不因「未登录」关闭；云侧计量路径可仍要求登录 Bearer（防滥用），**不得**把「能 Capture 摘录」做成必须登录。细则以产品文档配额表为准。

### 2. 数据归属（处理生命周期 ≠ Recall 权重）

| 数据                                                   | 归属                                               | 云同步（ADR-017） | 普通退出登录                                               |
| ------------------------------------------------------ | -------------------------------------------------- | ----------------- | ---------------------------------------------------------- |
| **书签壳**（Chrome 灌库 / 本机第三方 bookmark Memory） | **Chrome Profile / 本机**                          | 否                | **保留**（若曾 remap 到账号桶 → 回迁 `localProfileId`）    |
| **摘录** `text_excerpt`（账号桶）                      | **当前 `accountId`**（经门闸 Import 或登录态写入） | **仅 Pro**        | **从本机删除**（Pro 宜先 flush）；**不**并进本地档装成无主 |
| **摘录**（未登录写在 `localProfileId`）                | **无主 / 本机档**                                  | 否（直至 Import） | **保留**——下一次登录的迁移门闸对象                         |
| **书签附注** `clues.note`                              | 随条目归属                                         | 见 ADR-017        | 随书签回迁或随账号摘录删除                                 |
| **账号凭证 / 同步态 / 云副本**                         | **Account**                                        | —                 | 清除本机 session/binding；云侧按同步与删号规则             |

换账号 **≠** 合并家产。共享 Profile 上的 Chrome 书签树是物理共用；产品须诚实，不假装按「人」切开书签林。  
**理论上不留外账号桶：** 每次退出须清掉本账号在本机的账号侧痕迹；门闸主路径不服务「别人落下的 accountId 桶」（脏桶另清）。

### 3. 登录迁移门闸（禁止静默 absorb）

**无主摘录 = 仅未登录期间创造、仍在 `localProfileId` 的 `text_excerpt`。**

登录成功后，若本地档存在此类无主摘录：

**必须弹窗**（美式英语），用户显式三选一：

1. **Import into this account** — 将无主摘录归属当前账号；本地档书签可一并归属本机工作库（不上云，ADR-017）。
2. **Export** — Backup 后，用户可再确认是否删除未导入副本（不得留下「既不导入又不处理」的糊态）。
3. **Delete** — 丢弃本机这批无主摘录，不进入当前账号。

- 无无主摘录 → 不弹窗（同账号再登、退出已清账号桶后的常见路径）。
- **禁止** `absorbLocalProfileIntoAccount` 式静默 remap。
- 导入只解决归属；**真上云仍须 Pro + 同步**（及隐私 ack）。
- 云上已有摘录时，开同步后的对齐仍按 ADR-017 摘录并集规则；门闸文案可提示。

### 4. 退出与被挤掉（清账号痕迹 · 口径 A）

| 动作                                 | 行为                                                                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| **扩展 Free / 未开同步退出**（默认） | 清扩展凭证；**书签回本地档**；**删除本机账号桶其余 Memory（含摘录）**；本地档无主摘录保留；**不**清本浏览器官网 session |
| **扩展 Pro 退出**                    | **先同步 flush**（失败则明示：重试 / 仍退出并告知云可能落后）；再同默认清账号桶；**不**开官网 `/logout`                 |
| **被挤掉**                           | 尽力 flush；同清账号桶；清凭证；本地档无主摘录保留；**不**踢官网                                                        |
| **官网 Account Sign out**            | 仅清本浏览器官网 session + UI 桥否态；**不**踢扩展、不清扩展账号桶                                                      |
| **删除账号**                         | 清扩展侧后可开 `/logout` 连带清本浏览器官网（注销例外）                                                                 |
| **显式 wipe 账号桶（含书签）**       | Settings 强确认 `clear_local`：不回迁书签，整桶清空                                                                     |

未登录 Recall / Capture：仅见 `localProfileId`（书签 + 无主摘录），**不再**带着「刚退出账号的整库」。

### 5. 与 ADR-017 的关系

- 云同步面仍仅 `text_excerpt`；书签不上云。
- 本 ADR 解释 **谁在何种权益下写摘录、登录如何归属、退出如何清账号痕迹**；不改变「书签林不进云并集」。

## 后果

**必须（已落地）：**

- 产品文档 §5.1 / 账户与同步 Normative 按本 ADR 改写；废弃「登录即静默归并」「退出 remap 回本地档当默认工作库」表述。
- `GET_LOGIN_MIGRATION_STATUS` / `RESOLVE_LOGIN_MIGRATION` + Side Panel / Settings 门闸 UI；拆除静默 absorb；门闸仅计本地档无主摘录。
- 扩展退出 `keep_local` / `flush_then_keep` → `clearAccountLibraryOnSignOut`；被挤掉同清。官网 Sign out **不解耦前**曾经 `SIGN_OUT_HANDOFF` 同清——**已改为退出解耦**，官网退出不再踢扩展。
- 设置/隐私文案：未登录可划存；Free 登录不增加本机能力；Pro = 摘录换机；**扩展**退出会清本机账号摘录。

**禁止：**

- 登录静默把本机摘录并进当前账号。
- 退出把账号摘录 remap 进本地档装成无主（导致再登录误弹门闸）。
- 将「能 Capture」做成必须登录或必须 Pro。

## 拒绝的替代

| 方案                           | 为何不选                                                     |
| ------------------------------ | ------------------------------------------------------------ |
| 摘录必须 Pro                   | 伤害下载即用与私有增量积累；定价过激                         |
| 未登录不可摘录、登录 Free 才可 | 与「未登录≟Free 权益」冲突；多一套无必要门禁                 |
| 退出默认 remap 账号库→本地档   | 与「无主=仅未登录创造」冲突；再登录必误弹门闸                |
| 登录静默 absorb                | 共享电脑串库                                                 |
| 门闸扫一切 `ownerId≠accountId` | 把退出暂存/脏桶与无主混为一谈；口径过宽                      |
| 官网/扩展退出强行对称下线      | 与「Connect 显式接通」不对称；共享场景可用文案说明，勿默契踢 |
