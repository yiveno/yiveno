# Card 卡片组件

一个卡片容器组件，用于组织和展示相关内容。

## ✨ 特性

- 🎨 **灵活布局** - 支持标题、内容、操作区域
- 🖼️ **图片支持** - 可包含图片或图标
- 🔧 **可交互** - 支持点击、悬停等交互
- 📦 **组合组件** - 可能包含 Icon 等基础组件

## 📦 安装

```typescript
import { Card } from '@/components'
```

## 🔗 依赖组件

本组件依赖以下基础组件：

- [Icon](../../base/Icon/README.md)

## 🎯 基础用法

### 默认用法

```vue
<script setup lang="ts">
import { Card } from '@/components'
</script>

<template>
  <Card />
</template>
```

## 💡 使用场景

### 基础卡片

```vue
<template>
  <Card title="卡片标题">
    <p>卡片内容</p>
  </Card>
</template>
```
