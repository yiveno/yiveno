## 研究名称

Yiveno Recall 体验研究（Time-to-Evidence / 找回可验证性）

## 你会做什么

- 使用 Yiveno Chrome 扩展保存/找回**你自己**的网页摘录与书签。
- 完成约 **10 个**「用口语描述以前存过的东西」的短任务（每次 ≤3 分钟）。
- 可选：用你**平时习惯的方式**（如书签文件夹、稍后读工具）完成对照任务。
- 会话可能**屏幕录制**（用于核对是否找对了资料；可要求暂停或重录）。

## 我们会收集什么

| 数据                         | 用途               | 存储                     |
| ---------------------------- | ------------------ | ------------------------ |
| 屏幕录制                     | 审计 TTE、ECS 标注 | 加密存储；仅研究团队     |
| 事件日志（query 时间、点击） | 计算 TTE-V / TTE-C | 不含 Chrome 全站 history |
| 简短问卷                     | 筛选与满意度       | 与录屏同目录             |
| 你的 Yiveno 库内 MemoryItem  | 任务设计           | **不**导出整库除非另签   |

**我们不会：** 读取未经过 Yiveno Capture 的完整浏览历史；不要求 Gmail/日历权限；不把摘录正文用于模型训练（当前产品边界）。
