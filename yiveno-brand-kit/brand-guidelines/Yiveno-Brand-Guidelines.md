# Yiveno 品牌视觉规范

> **品牌主张：Grow with intention.** 以有意识的成长，建立人与产品、环境与未来之间更自然的连接。

## 1. 品牌概览

Yiveno 的视觉识别建立在一个“向上生长、向外连接、向下扎根”的符号之上。主干与分叉表达成长和关系，顶部圆点代表意识、焦点或新的可能，底部椭圆轨道则形成一种稳定、连续、可持续的基础。整体气质应当**克制、温和、可信，同时具有辨识度**。

品牌不追求喧闹的科技感，而是通过柔和渐变、留白、细线轨道与自然材质，呈现“有机精确”的高级感。

## 2. Logo 系统

### 2.1 主标

主标由 Yiveno 图形标志与小写字标组成。图形标志优先保持原始比例和渐变关系，不得重新描摹、压扁、拉伸或增加阴影。建议在浅色底上使用深色主标，在深色底上使用反白或 Sage Mist 单色版本。

### 2.2 安全空间

以顶部圆点的直径作为 `x`。Logo 四周至少保留 `1x` 的安全空间；在大幅广告、包装正面或发布会主视觉中，建议使用 `2x` 至 `3x` 的安全空间。

### 2.3 最小尺寸

数字端图形标志不小于 24 px；带字标的横向组合不小于 120 px。印刷端图形标志不小于 8 mm；带字标组合不小于 28 mm。若小于建议尺寸，使用 icon-only 版本。

### 2.4 禁止事项

不得改变图形节点数量，不得旋转标志，不得使用未经批准的描边，不得将标志置于低对比度背景，不得添加发光、投影、渐变外描边，不得将字标改为全大写，不得把轨道线裁切到难以识别的程度。

## 3. 色彩系统

| 颜色名称       |             数字值 | 使用建议                     |
| -------------- | -----------------: | ---------------------------- |
| Forest Ink     |          `#192420` | 主标、深色底、标题、核心 CTA |
| Deep Moss      |          `#4B6054` | 次级深色、渐变终点、交互强调 |
| Sage Mist      |          `#9BB3A6` | 插图、状态、轻量强调         |
| Soft Dew       |          `#CFE2D7` | 高光、浅色底、hover 状态     |
| Ring Veil      | `#CED8CB` / 22–54% | 轨道线、分割线、背景纹理     |
| Warm Porcelain |          `#F4F5F0` | 页面主背景、纸张、包装       |
| Carbon         |          `#202824` | 正文与辅助信息               |

深色区域优先使用 Forest Ink，辅以 Deep Moss 的纵向渐变。浅色区域优先使用 Warm Porcelain，搭配 Soft Dew 的柔和光晕。Ring Veil 只能作为低对比度结构线，不应承担正文信息。

## 4. 字体系统

数字产品首选 **Manrope**，中文搭配 **Noto Sans SC**。标题建议使用 600–700 字重，正文使用 400–500 字重，辅助文字使用 400 字重。英文品牌字标使用小写 `yiveno`，字距略微放宽；中文标题应避免过度紧缩。

| 层级    | 推荐字号 | 字重 | 行高 |
| ------- | -------: | ---: | ---: |
| Display | 56–72 px |  600 | 1.05 |
| H1      | 40–48 px |  600 | 1.10 |
| H2      | 28–32 px |  600 | 1.20 |
| Body    | 16–18 px |  400 | 1.60 |
| Caption | 12–14 px |  500 | 1.40 |

## 5. 版式与图形语言

版式使用 8 px 基准网格，卡片圆角建议 20–28 px，按钮圆角建议 999 px 或 14 px。大面积留白是品牌识别的一部分；一张画面尽量只保留一个主要焦点。

轨道线图形应保持 1–2 px 的细度，并使用 Ring Veil 或 Soft Dew。轨道可以作为背景纹理、信息分组边界或动效路径，但不应喧宾夺主。建议建立由 1、2、3 个同心椭圆构成的基础图形单元，并与顶部圆点形成呼应。

## 6. 图像与材质

图像方向是自然光、触感材料、柔和阴影和真实表面。优先使用温润纸张、磨砂表面、透明树脂、浅色石材、植物纤维与水面反射。避免高饱和霓虹、赛博朋克、过度锐化、冷蓝科技背景和拥挤的商业库存图风格。

产品图片应保留足够负空间，以容纳简短标题或 CTA。品牌主视觉中的绿色应以低饱和的森林、苔藓与鼠尾草为主，而不是荧光绿。

## 7. 语气与文案

Yiveno 的语言应当简洁、清楚、温和而有方向感。推荐使用“让成长更有意识”“从连接开始”“为长期而设计”等表达。避免“颠覆”“革命性”“宇宙级”等夸张词汇。英文表达尽量短句化，例如 `Grow with intention.`、`Built for meaningful connection.`、`A calmer way forward.`

## 8. 数字产品与可访问性

正文文字与 Warm Porcelain 背景之间应保持足够对比度；深色按钮使用 Forest Ink，文字使用白色或 Warm Porcelain。大面积浅绿仅用于背景，不用于长段正文。交互状态除颜色外，应同时通过形状、下划线、图标或位置变化表达。

## 9. 动效建议

动效应模拟轻微的轨道运行、呼吸、浮动与生长。推荐 400–700 ms 的缓动过渡，避免弹跳和高频闪烁。Logo 动效可以从中心圆点出现，随后主干向下延展，最后轨道线依次显现；动效结束后必须回到清晰、静止的标准标志状态。

## 10. 交付资产

本套文件包含：logo 原始 SVG、PNG 参考图、品牌规范、色彩与图形资产、社交媒体视觉、产品主视觉、包装卡片与文具场景图。正式生产前，建议由设计团队确认最终字标字形、印刷专色、CMYK 转换与具体产品类别的包装法规信息。
